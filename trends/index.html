How to read this

  • Every calendar day in this interval was observed, including quiet days.
  • Additions and removals describe register records, not vacancies, workers, visa grants or sponsorship willingness.
  • Net movement is additions minus removals inside the observed period. It is not an economic growth rate.
  • Rating changes are preserved separately: 27 downgrades and 0 upgrades in this period.
  • The public JSON contains aggregate counts only. Employer-level history stays in the private evidence archive.
